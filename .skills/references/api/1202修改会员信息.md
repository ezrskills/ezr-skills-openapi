### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1202 |
| 接口名称 | 会员修改 |
| 接口地址 | `/api/cvip/VipUpdate` |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |


#### 功能描述

用于线下修改会员的基础信息，不包含消费习惯信息。该接口通过会员线下卡号（OldCode）定位会员，支持批量修改（最多100条）。

## 请求结构

### 外层请求参数

所有接口的外层请求参数结构一致：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名，参见签名规则 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串，结构因接口而异 |

### 请求示例

```json
{
    "AppId": "1001",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260316143052",
    "AppSystem": "ERP",
    "Args": "[{\"OldCode\":\"VIP001\",\"MobileNo\":\"13800138000\",\"Name\":\"张三\"}]"
}
```

## 响应结构

### 标准响应格式

```json
{
    "Status": true,
    "StatusCode": 200,
    "Msg": "成功",
    "Sign": "响应签名",
    "Timestamp": "20260316143052",
    "Result": 1
}
```

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Status | bool | 请求是否成功 |
| StatusCode | int | 状态码，200表示成功 |
| Msg | string | 响应消息 |
| Sign | string | 响应签名，可用于验证响应真实性 |
| Timestamp | string | 响应时间戳 |
| Result | int | 影响的行数 |

### 响应签名验证

响应签名生成规则与请求签名相同：
```
Sign = SHA1("AppId={AppId}&Timestamp={Timestamp}&Token={Token}")
```

## 接口详情

### 会员修改（1202）

#### 接口基本信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1202 |
| 接口名称 | 会员修改 |
| 接口地址 | `/api/cvip/VipUpdate` |
| 请求方式 | POST |
| 功能描述 | 线下修改会员基础信息，按线下卡号修改，支持批量（最多100条） |

#### 业务请求参数（Args）

Args 为 JSON 数组，支持批量修改，每个元素包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 是 | 会员线下卡号（最多20位） |
| MobileNo | string | 否 | 手机号码（最多11位） |
| Name | string | 否 | 会员姓名（最多20位） |
| PassWord | string | 否 | 密码（最多32位） |
| Sex | string | 否 | 性别：`1`=男，`2`=女，`0`=未知，或直接传"男"/"女"/"未知" |
| Birthday | string | 否 | 生日，格式 `yyyy-MM-dd` |
| WeibNo | string | 否 | 微博号码（最多32位） |
| QqNo | string | 否 | QQ号码（最多20位） |
| TbNo | string | 否 | 淘宝号码（最多32位） |
| Email | string | 否 | 邮箱（最多32位） |
| Province | string | 否 | 省份 |
| City | string | 否 | 城市 |
| County | string | 否 | 区县 |
| ServShop | string | 否 | 服务门店编码（最多16位） |
| ServUser | string | 否 | 服务导购工号 |
| EditCurrentServShop | bool | 否 | 默认true，true根据服务门店修改门店、导购，false服务门店是当前门店不修改。 |
| WxOpenId | string | 否 | 微信服务号openid，用于后面发送公众号类目消息用 |

#### 业务响应参数（Result）

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Result | int | 影响的行数，成功修改的会员数量 |

#### 请求示例

**单条修改**
```json
{
    "AppId": "1001",
    "Sign": "A1B2C3D4E5F6G7H8I9J0",
    "Timestamp": "20260316143052",
    "AppSystem": "ERP",
    "Args": "[{\"OldCode\":\"VIP001\",\"MobileNo\":\"13800138000\",\"Name\":\"张三\",\"Sex\":\"男\",\"Birthday\":\"1990-01-15\"}]"
}
```

**批量修改**
```json
{
    "AppId": "1001",
    "Sign": "A1B2C3D4E5F6G7H8I9J0",
    "Timestamp": "20260316143052",
    "AppSystem": "ERP",
    "Args": "[{\"OldCode\":\"VIP001\",\"MobileNo\":\"13800138001\",\"Name\":\"张三\"},{\"OldCode\":\"VIP002\",\"MobileNo\":\"13800138002\",\"Name\":\"李四\"}]"
}
```

#### 响应示例

**成功响应**
```json
{
    "Status": true,
    "StatusCode": 200,
    "Msg": "成功",
    "Sign": "RESPONSE_SIGN_VALUE",
    "Timestamp": "20260316143052",
    "Result": 1
}
```

## 完整示例代码

### 业务服务示例

```csharp
using System;
using System.Collections.Generic;
using EZP.Framework.Util.HttpClientFactory;
using EZR.OP.ThirdPartyProxy.Bussiness.OpenApi.Client;

/// <summary>
/// 会员服务
/// </summary>
public static class VipService
{
    private static readonly IEZROpenApiClient _openApiClient = EZP.Framework.Util.HttpClientFactory.EzpFrameworkDI.GetRequiredService<IEZROpenApiClient>();

    /// <summary>
    /// 修改会员信息（接口编号：1202）
    /// </summary>
    /// <param name="request">请求参数列表（最多100条）</param>
    /// <returns>返回影响的行数</returns>
    public static BaseApiResInfo<int> UpdateVipInfo(List<VipUpdateRequest> request)
    {
        if (request == null || request.Count == 0)
        {
            return new BaseApiResInfo<int>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "请求参数不能为空"
            };
        }

        if (request.Count > 100)
        {
            return new BaseApiResInfo<int>
            {
                Status = false,
                StatusCode = 1002,
                Msg = "批量修改最多支持100条"
            };
        }

        return _openApiClient.PostOpenApi<List<VipUpdateRequest>, int>("/api/cvip/VipUpdate", request);
    }
}

// 会员修改请求参数（接口编号：1202）
public class VipUpdateRequest
{
    /// <summary>
    /// 会员线下卡号（必填）
    /// </summary>
    public string OldCode { get; set; }

    /// <summary>
    /// 手机号码
    /// </summary>
    public string MobileNo { get; set; }

    /// <summary>
    /// 会员姓名
    /// </summary>
    public string Name { get; set; }

    /// <summary>
    /// 密码
    /// </summary>
    public string PassWord { get; set; }

    /// <summary>
    /// 性别：1=男，2=女，0=未知，或直接传"男"/"女"/"未知"
    /// </summary>
    public string Sex { get; set; }

    /// <summary>
    /// 生日，格式 yyyy-MM-dd
    /// </summary>
    public string Birthday { get; set; }

    /// <summary>
    /// 微博号码
    /// </summary>
    public string WeibNo { get; set; }

    /// <summary>
    /// 证件号码
    /// </summary>
    public string IdCardNo { get; set; }

    /// <summary>
    /// QQ号码
    /// </summary>
    public string QqNo { get; set; }

    /// <summary>
    /// 淘宝号码
    /// </summary>
    public string TbNo { get; set; }

    /// <summary>
    /// 邮箱
    /// </summary>
    public string Email { get; set; }

    /// <summary>
    /// 省份
    /// </summary>
    public string Province { get; set; }

    /// <summary>
    /// 城市
    /// </summary>
    public string City { get; set; }

    /// <summary>
    /// 区县
    /// </summary>
    public string County { get; set; }

    /// <summary>
    /// 服务门店编码
    /// </summary>
    public string ServShop { get; set; }

    /// <summary>
    /// 服务导购工号
    /// </summary>
    public string ServUser { get; set; }
}

// 使用示例
class Program
{
    static void Main()
    {
        // 单条修改
        var request = new List<VipUpdateRequest>
        {
            new VipUpdateRequest
            {
                OldCode = "VIP001",
                MobileNo = "13800138000",
                Name = "张三",
                Sex = "男",
                Birthday = "1990-01-15"
            }
        };
        var result = VipService.UpdateVipInfo(request);

        if (result.Status)
        {
            Console.WriteLine($"修改成功，影响行数: {result.Result}");
        }
        else
        {
            Console.WriteLine($"错误码: {result.StatusCode}, 错误信息: {result.Msg}");
        }

        // 批量修改
        var batchRequest = new List<VipUpdateRequest>
        {
            new VipUpdateRequest { OldCode = "VIP001", MobileNo = "13800138001", Name = "张三" },
            new VipUpdateRequest { OldCode = "VIP002", MobileNo = "13800138002", Name = "李四" }
        };
        var batchResult = VipService.UpdateVipInfo(batchRequest);

        if (batchResult.Status)
        {
            Console.WriteLine($"批量修改成功，影响行数: {batchResult.Result}");
        }
    }
}
```
