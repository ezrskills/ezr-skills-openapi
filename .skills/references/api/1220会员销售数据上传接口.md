### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1220 |
| 接口名称 | 会员销售数据上传 |
| 接口地址 | `/api/CSale/VipSaleUpload` |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |


#### 功能描述

用于将第三方系统的会员销售交易数据批量上传到EZR平台，支持销售数据同步、积分计算、会员消费分析和多渠道数据整合。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON数组字符串，每个元素包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| ShopCode | string | 是 | 门店编码 |
| SaleNo | string | 是 | 订单编号（最长26位，品牌范围内唯一） |
| RefSaleNo | string | 否 | 关联订单编号（退货时填写原销售单号） |
| SaleType | string | 是 | 订单状态：`S`-销售，`R`-退货，`C`-换货 |
| VipOffCode | string | 否 | 会员线下卡号 |
| SaleDate | string | 是 | 销售日期（格式：yyyy-MM-dd HH:mm:ss） |
| SaleQty | int | 是 | 销售总数量 |
| SaleMoney | decimal | 是 | 订单金额 |
| RetailPrice | decimal | 否 | 零售总价 |
| SaleProdQty | int | 否 | 销售商品品项数 |
| SaleOrigMoney | decimal | 是 | 订单原始金额 |
| SalePayMoney | decimal | 是 | 支付总金额 |
| SalerCode | string | 否 | 销售导购工号 |
| CmdShopCode | string | 否 | 推荐门店编码 |
| CmdSalerCode | string | 否 | 推荐导购工号 |
| Dtls | array | 否 | 商品明细列表 |
| PayDtls | array | 否 | 支付明细列表 |
| SalesPerformances | array | 否 | 业绩分配列表 |
| DataOrigin | int | 否 | 数据来源（默认0=线下） |
| SaleCategory | int | 否 | 销售分类 |
| CalcBonusType | int | 否 | 积分计算类型 |
| IsNotCalcDiscount | bool | 否 | 是否不计算折扣，默认false |
| SaleDiscount | decimal | 否 | 销售折扣 |

### 商品明细参数（Dtls）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| ProdCode | string | 是 | 商品条码 |
| RetailPrice | decimal | 是 | 零售单价 |
| SalePrice | decimal | 否 | 实际售价 |
| SaleQty | int | 是 | 销售件数 |
| SaleMoney | decimal | 否 | 销售金额 |
| SalePayMoney | decimal | 否 | 支付金额 |
| SalerCode | string | 否 | 导购工号 |
| RefSaleNo | string | 否 | 关联订单编号 |

### 支付明细参数（PayDtls）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| PayOrigin | string | 是 | 支付方式编码 |
| PayMoney | string | 是 | 支付金额 |

### 业绩分配参数（SalesPerformances）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| UserCode | string | 是 | 导购工号 |
| Proportion | decimal | 是 | 分配比例 |
