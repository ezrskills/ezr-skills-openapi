### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1203 |
| 接口名称 | 会员查询 |
| 接口地址 | `/api/cvip/VipGet` |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |


#### 功能描述

用于查询会员的详细信息，支持多种查询方式：线下卡号查询、电子卡号查询、手机号查询、微信OpenID查询、微信UnionID查询。

## 请求结构

### 外层请求参数

所有接口的外层请求参数结构一致：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名，参见签名规则 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串，结构因接口而异 |

### 请求示例

```json
{
    "AppId": "1001",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260316143052",
    "AppSystem": "ERP",
    "Args": "{\"MobileNo\":\"13800138000\"}"
}
```

## 响应结构

### 标准响应格式

```json
{
    "Status": true,
    "StatusCode": 200,
    "Msg": "成功",
    "Sign": "响应签名",
    "Timestamp": "20260316143052",
    "Result": {
        // 业务返回数据，根据具体接口而定
    }
}
```

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Status | bool | 请求是否成功 |
| StatusCode | int | 状态码，200表示成功 |
| Msg | string | 响应消息 |
| Sign | string | 响应签名，可用于验证响应真实性 |
| Timestamp | string | 响应时间戳 |
| Result | object | 业务返回数据，结构因接口而异 |

### 响应签名验证

响应签名生成规则与请求签名相同：
```
Sign = SHA1("AppId={AppId}&Timestamp={Timestamp}&Token={Token}")
```

## 接口详情

### 会员查询（1203）

#### 接口基本信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1203 |
| 接口名称 | 会员查询 |
| 接口地址 | `/api/cvip/VipGet` |
| 请求方式 | POST |
| 功能描述 | 根据会员卡号、手机号或微信ID查询会员信息 |

#### 业务请求参数（Args）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 否* | 会员线下卡号（最多20位） |
| Code | string | 否* | 会员电子卡号（最多20位） |
| MobileNo | string | 否* | 手机号码（最多11位） |
| WxUnionID | string | 否* | 微信 UnionID |
| WxOpenID | string | 否* | 微信 OpenID |
| ThirdPartyId | int | 否* | 所属平台 1:京东 2:天猫 10:抖音 |
| ThirdPartyUnionId | string | 否* | 第三方会员唯一标识 (京东:pin;淘宝:ouid,抖音:openid) |

> *以上参数至少填写一个

#### 业务响应参数（Result）

| 参数名 | 类型 | 说明 |
|--------|------|------|
| OldCode | string | 会员线下卡号 |
| Code | string | 会员电子卡号 |
| Grade | string | 会员等级 |
| NickName | string | 会员昵称 |
| MobileNo | string | 手机号码 |
| Name | string | 会员姓名 |
| Sex | string | 会员性别 |
| PassWord | string | 会员密码 |
| Birthday | string | 会员生日（yyyy-MM-dd） |
| WxNo | string | 微信号码 |
| WxCode | string | 微信会员卡原始 Code |
| WxUnionId | string | 微信 UnionID |
| Email | string | 邮箱 |
| RegShop | string | 开卡门店 |
| RegDate | string | 开卡日期 |
| Province | string | 省份 |
| City | string | 城市 |
| County | string | 区县 |
| Bonus | int | 当前积分 |
| BonusTotal | int | 累计积分 |
| ServShop | string | 所属服务门店 |
| ServUser | string | 所属服务导购 |
| Discount | decimal | 会员折扣 |

{
    private static readonly IEZROpenApiClient _openApiClient = EZP.Framework.Util.HttpClientFactory.EzpFrameworkDI.GetRequiredService<IEZROpenApiClient>();

    /// <summary>
    /// [EZR-API:1203] 查询会员信息
    /// 查询会员信息
    /// </summary>
    /// <param name="request">请求参数</param>
    /// <returns></returns>
    public static BaseApiResInfo<VipGetResult> GetVipInfo(VipGetRequest request)
    {
        if (string.IsNullOrWhiteSpace(request.OldCode) &&
            string.IsNullOrWhiteSpace(request.Code) &&
            string.IsNullOrWhiteSpace(request.MobileNo) &&
            string.IsNullOrWhiteSpace(request.WxUnionID) &&
            string.IsNullOrWhiteSpace(request.WxOpenID) &&
            string.IsNullOrWhiteSpace(request.ThirdPartyUnionId))
        {
            return new BaseApiResInfo<VipGetResult>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "查询参数不能为空，至少提供一个查询条件"
            };
        }

        return _openApiClient.PostOpenApi<VipGetRequest, VipGetResult>("/api/cvip/VipGet", request);
    }
}
