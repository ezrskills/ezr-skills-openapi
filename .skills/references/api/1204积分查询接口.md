### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1204 |
| 接口名称 | 积分查询 |
| 接口地址 | /api/cvip/vipbonusget |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于查询会员积分信息，包括当前积分余额、累计积分、冻结积分等，支持多种会员识别方式查询。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 否* | 会员线下卡号 |
| Code | string | 否* | 会员电子卡号 |
| MobileNo | string | 否* | 手机号码 |
| HaveTrans | string | 否 | 是否返回交易记录，true/false |

> *会员标识参数（OldCode、Code、MobileNo）至少填写一个

### 请求示例

```json
{
    "AppId": "EZP-ZhuTest02",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260324143052",
    "AppSystem": "POS",
    "Args": "{\"OldCode\":\"EZ00000277735638\",\"Code\":\"\",\"MobileNo\":\"\",\"HaveTrans\":\"false\"}"
}
```

using System;
using System.Collections.Generic;
using EZP.Framework.Util.HttpClientFactory;
using EZR.OP.ThirdPartyProxy.Bussiness.OpenApi.Client;

/// <summary>
/// 积分查询服务
/// </summary>
public static class BonusQueryService
{
    private static readonly IEZROpenApiClient _openApiClient = EZP.Framework.Util.HttpClientFactory.EzpFrameworkDI.GetRequiredService<IEZROpenApiClient>();

    /// <summary>
    /// [EZR-API:1204] 查询会员积分
    /// 查询会员积分（接口编号：1204）
    /// </summary>
    /// <param name="request">请求参数</param>
    /// <returns></returns>
    public static BaseApiResInfo<BonusQueryResult> GetVipBonus(BonusQueryRequest request)
    {
        if (request == null)
        {
            return new BaseApiResInfo<BonusQueryResult>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "请求参数不能为空"
            };
        }

        if (string.IsNullOrWhiteSpace(request.OldCode) &&
            string.IsNullOrWhiteSpace(request.Code) &&
            string.IsNullOrWhiteSpace(request.MobileNo))
        {
            return new BaseApiResInfo<BonusQueryResult>
            {
                Status = false,
                StatusCode = 1002,
                Msg = "会员标识参数（OldCode、Code、MobileNo）至少填写一个"
            };
        }

        return _openApiClient.PostOpenApi<BonusQueryRequest, BonusQueryResult>("/api/cvip/vipbonusget", request);
    }
}

// 使用示例
class Program
{
    static void Main()
    {
        // 查询会员积分（不含交易记录）
        var request = new BonusQueryRequest
        {
            OldCode = "EZ00000277735638",
            Code = "",
            MobileNo = "",
            HaveTrans = "false"
        };

        var result = BonusQueryService.GetVipBonus(request);

        if (result.Status && result.Result != null)
        {
            Console.WriteLine($"会员线下卡号: {result.Result.OldCode}");
            Console.WriteLine($"会员电子卡号: {result.Result.Code}");
            Console.WriteLine($"手机号码: {result.Result.MobileNo}");
            Console.WriteLine($"当前积分余额: {result.Result.Bonus}");
            Console.WriteLine($"累计积分: {result.Result.BonusTotal}");
        }
        else
        {
            Console.WriteLine($"错误码: {result.StatusCode}, 错误信息: {result.Msg}");
        }

        // 查询会员积分（含交易记录）
        var requestWithTrans = new BonusQueryRequest
        {
            OldCode = "EZ00000277735638",
            HaveTrans = "true"
        };

        var resultWithTrans = BonusQueryService.GetVipBonus(requestWithTrans);

        if (resultWithTrans.Status && resultWithTrans.Result != null)
        {
            Console.WriteLine($"当前积分余额: {resultWithTrans.Result.Bonus}");
            if (resultWithTrans.Result.Trans != null && resultWithTrans.Result.Trans.Count > 0)
            {
                Console.WriteLine($"交易记录数: {resultWithTrans.Result.Trans.Count}");
                foreach (var trans in resultWithTrans.Result.Trans)
                {
                    Console.WriteLine($"交易ID: {trans.TransId}, 积分值: {trans.TransVal}, 交易时间: {trans.TransDate}");
                }
            }
        }
        else
        {
            Console.WriteLine($"错误码: {resultWithTrans.StatusCode}, 错误信息: {resultWithTrans.Msg}");
        }
    }
}
