## 概述

本文档描述如何对接EZR开放平台的推送回调接口。推送回调与普通接口的主要区别在于：

- 推送没有现成的接口地址，需要自定义接口地址
- 推送是对接其他第三方的接口或者自定义业务处理

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Brand | string | 是 | 所属品牌编号 |
| OldCode | string | 是 | 客户卡号 |
| Code | string | 是 | EZR卡号，线上卡号 |
| ChangeBonus | int | 是 | 变动积分，正数为增加，负数为减少 |
| Bonus | int | 是 | 变动后积分余额 |
| BonusTotal | int | 否 | 累计积分 |
| ChangeType | string | 是 | 变动类型：1=增加，2=减少 |
| ChangeReason | string | 否 | 变动原因 |
| ChangeTime | string | 是 | 变动时间，yyyy-MM-dd HH:mm:ss格式 |
| Remark | string | 否 | 备注 |
| MobileNo | string | 否 | 手机号 |
| Name | string | 否 | 会员姓名 |
| Grade | string | 否 | 会员等级名称 |
| RegShop | string | 否 | 开卡门店编码 |
| ServShop | string | 否 | 服务门店编码 |
| ServUser | string | 否 | 服务导购编码 |
| OrderNo | string | 否 | 关联订单号 |
| DyOpenId | string | 否 | 抖音会员唯一标示 |
| JdXid | string | 否 | 京东唯一标识xid |

## 接入流程

### 1. 项目结构介绍

| 项目名称 | 描述 | 备注 |
| -------- | -------- | -------- |
| `*.ApiHost、*.Site` | 接口层 | Web API 宿主应用程序（入口点，.NET 5.0） |
| `*.ApiModel` | 实体层 | 数据模型、实体和 DTO（.NET Standard 2.0） |
| `*.Bussiness` | 业务层 | 业务逻辑层（.NET Standard 2.0） |
| `*.Intergration` | 领域层 | 用于调用其他业务grpc领域方法 |
| `*.Repository` | 数据仓储层 | 访问数据库相关的逻辑，执行增删改查（.NET Standard 2.0） |
| `*.Utils` | 工具层 | 通用帮助类,共享工具类（.NET Standard 2.0） |
| `*.Test` | 单元测试层 | 用于单元测试实例 |

开发流程说明：

1. **ApiModel 层**：生成数据模型实体，定义请求/响应对象和实体类
2. **Business 层**：创建 `IYourService` 接口和 `YourService` 实现，生成业务处理类
3. **ApiHost 层**：创建 `YourController` 控制器，继承 `Controller`，生成业务操作接口层
4. **自动注册**：Autofac 将自动装配依赖项
