## 请求结构

### 外层请求参数

所有接口的外层请求参数结构一致：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名，参见签名规则 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串，结构因接口而异 |

```json
{
    "AppId": "EZP-ZhuTest02",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
```

## 响应结构

### 标准响应格式

```json
{
    "Status": true,
    "StatusCode": 200,
    "Msg": "成功",
    "Sign": "响应签名",
    "Timestamp": "20260320143052",
    "Result": "操作成功"
}
```

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Status | bool | 请求是否成功 |
| StatusCode | int | 状态码，200表示成功 |
| Msg | string | 响应消息 |
| Sign | string | 响应签名，可用于验证响应真实性 |
| Timestamp | string | 响应时间戳 |
| Result | string | 业务返回数据，成功时返回操作结果描述 |

### 响应签名验证

响应签名生成规则与请求签名相同：
```
Sign = SHA1("AppId={AppId}&Timestamp={Timestamp}&Token={Token}")
```

```csharp
using System;
using EZP.Framework.Util.HttpClientFactory;
using EZR.OP.ThirdPartyProxy.Bussiness.OpenApi.Client;

/// <summary>
/// 会员等级变动服务
/// </summary>
public static class VipGradeService
{
    private static readonly IEZROpenApiClient _openApiClient = EZP.Framework.Util.HttpClientFactory.EzpFrameworkDI.GetRequiredService<IEZROpenApiClient>();

    /// <summary>
    /// [EZR-API:1207] 上传会员等级变动
    /// 上传会员等级变动（接口编号：1207）
    /// </summary>
    /// <param name="request">请求参数</param>
    /// <returns></returns>
    public static BaseApiResInfo<string> UpdateGrade(VipGradeUpdateRequest request)
    {
        if (request == null)
        {
            return new BaseApiResInfo<string>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "请求参数不能为空"
            };
        }

        if (string.IsNullOrWhiteSpace(request.OldCode))
        {
            return new BaseApiResInfo<string>
            {
                Status = false,
                StatusCode = 1002,
                Msg = "会员卡号不能为空"
            };
        }

        if (string.IsNullOrWhiteSpace(request.Grade))
        {
            return new BaseApiResInfo<string>
            {
                Status = false,
                StatusCode = 1003,
                Msg = "等级名称不能为空"
            };
        }

        if (string.IsNullOrWhiteSpace(request.ChangeTime))
        {
            request.ChangeTime = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss");
        }

        return _openApiClient.PostOpenApi<VipGradeUpdateRequest, string>("/api/cvip/VipGradeUpdate", request);
    }
}
```
