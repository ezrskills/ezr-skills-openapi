| 项目 | 说明 |
|------|------|
| 接口编号 | 1201 |

| 接口地址 | `/api/CVip/VipAdd` |

## 请求结构

### 外层请求参数

所有接口的外层请求参数结构一致：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名，参见签名规则 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串，结构因接口而异 |

### 请求示例

```json
{
    "AppId": "1001",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260316143052",
    "AppSystem": "ERP",
    "Args": "{\"OldCode\":\"VIP001\",\"MobileNo\":\"13800138000\",\"Name\":\"张三\",\"RegShop\":\"SHOP001\",\"RegDate\":\"2026-03-16\"}"
}
```

## 响应结构

### 标准响应格式

```json
{
    "Status": true,
    "StatusCode": 200,
    "Msg": "成功",
    "Sign": "响应签名",
    "Timestamp": "20260316143052",
    "Result": {
        // 业务返回数据，根据具体接口而定
    }
}
```

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Status | bool | 请求是否成功 |
| StatusCode | int | 状态码，200表示成功 |
| Msg | string | 响应消息 |
| Sign | string | 响应签名，可用于验证响应真实性 |
| Timestamp | string | 响应时间戳 |
| Result | object | 业务返回数据，结构因接口而异 |

### 响应签名验证

响应签名生成规则与请求签名相同：
```
Sign = SHA1("AppId={AppId}&Timestamp={Timestamp}&Token={Token}")
```

## 接口详情

### 会员线下开卡接入（1201）

#### 接口基本信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1201 |
| 接口名称 | 会员线下开卡接入 |
| 接口地址 | `/api/CVip/VipAdd` |
| 请求方式 | POST |
| 功能描述 | 将线下开卡会员数据同步到EZR平台，如已存在线下卡号则更新会员信息 |

#### 业务请求参数（Args）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 是 | 会员线下卡号（最长20位） |
| Grade | string | 否 | 会员等级名称（最长16位） |
| NickName | string | 否 | 会员昵称（最长32位） |
| MobileNo | string | 否 | 手机号码（最长11位） |
| Name | string | 否 | 会员姓名 |
| Sex | string | 否 | 会员性别（1位：M-男，F-女） |
| Birthday | string | 否 | 会员生日（格式：yyyy-MM-dd） |
| WxNo | string | 否 | 微信号码（最长32位） |
| WxUnionId | string | 否 | 微信UnionID（最长64位） |
| PassWord | string | 否 | 密码（MD5小写，最长32位） |
| WeibNo | string | 否 | 微博号码（最长32位） |
| IdCardNo | string | 否 | 证件号码（最长20位） |
| QqNo | string | 否 | QQ号码（最长20位） |
| TbNo | string | 否 | 淘宝号码（最长32位） |
| Email | string | 否 | 邮箱（最长32位） |
| RegShop | string | 是 | 开卡门店编码（最长16位） |
| RegDate | string | 是 | 入会日期（格式：yyyy-MM-dd） |
| Province | string | 否 | 省份 |
| City | string | 否 | 城市 |
| County | string | 否 | 区县 |
| ServShop | string | 否 | 服务门店编码（最长16位） |
| ServUser | string | 否 | 服务导购工号（最长16位） |

#### 业务响应参数（Result）

| 参数名 | 类型 | 说明 |
|--------|------|------|
| OldCode | string | 会员线下卡号 |
| Code | string | 会员电子卡号 |
| NewVip | bool | 是否新会员，true新会员，false老会员 |

using System;
using EZP.Framework.Util.HttpClientFactory;
using EZR.OP.ThirdPartyProxy.Bussiness.OpenApi.Client;

/// <summary>
/// 会员开卡服务
/// </summary>
public static class VipAddService
{
    private static readonly IEZROpenApiClient _openApiClient = EZP.Framework.Util.HttpClientFactory.EzpFrameworkDI.GetRequiredService<IEZROpenApiClient>();

    /// <summary>
    /// [EZR-API:1201] 会员线下开卡接入
    /// 会员线下开卡接入
    /// </summary>
    /// <param name="request">请求参数</param>
    /// <returns></returns>
    public static BaseApiResInfo<VipAddResult> AddVip(VipAddRequest request)
    {
        if (string.IsNullOrWhiteSpace(request.OldCode))
        {
            return new BaseApiResInfo<VipAddResult>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "线下卡号不能为空"
            };
        }

        if (string.IsNullOrWhiteSpace(request.RegShop))
        {
            return new BaseApiResInfo<VipAddResult>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "开卡门店不能为空"
            };
        }

        if (string.IsNullOrWhiteSpace(request.RegDate))
        {
            return new BaseApiResInfo<VipAddResult>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "入会日期不能为空"
            };
        }

        return _openApiClient.PostOpenApi<VipAddRequest, VipAddResult>("/api/CVip/VipAdd", request);
    }
}
