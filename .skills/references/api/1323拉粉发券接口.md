### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1323 |
| 接口名称 | 拉粉发券 |
| 接口地址 | /api/cvip/coupsendasync |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于向粉丝（潜在会员）异步发放优惠券，支持批量发券，适用于拉新活动、粉丝关怀等场景。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| ValidType | string | 是 | 有效期类型：TS=固定时间 |
| BegDate | string | 是 | 有效期开始，格式 yyyy-MM-dd |
| WxOpenID | string | 否 | 微信OpenID |
| WxUnionID | string | 否 | 微信UnionID |
| CoupGrpId | long | 是 | 券库ID |
| EndDate | string | 是 | 有效期结束，格式 yyyy-MM-dd |
| CoupNo | string | 否 | 券编号 |
| RegShop | string | 否 | 注册门店编码 |
| MobileNo | string | 否 | 手机号码 |
| OldCode | string | 否 | 会员线下卡号 |
| CoupGrpCode | string | 否 | 券库编码 |
