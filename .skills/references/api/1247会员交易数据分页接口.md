### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1247 |
| 接口名称 | 会员交易数据分页 |
| 接口地址 | /api/csale/vipsalepageget |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于分页查询会员交易数据，支持按会员、门店、时间等条件筛选，适用于会员消费分析、交易数据同步等场景。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| ShopCode | string | 否 | 门店编码 |
| OldCode | string | 否 | 会员线下卡号 |
| VipCode | string | 否 | 会员电子卡号 |
| WxOpenID | string | 否 | 微信OpenID |
| WxUnionID | string | 否 | 微信UnionID |
| MobileNo | string | 否 | 手机号码 |
| DataOrigin | int | 否 | 数据来源 |
| SaleDateStart | string | 否 | 销售日期开始，格式 yyyy-MM-dd |
| SaleDateEnd | string | 否 | 销售日期结束，格式 yyyy-MM-dd |
| ImportTimeStart | string | 否 | 导入时间开始，格式 yyyy-MM-dd |
| ImportTimeEnd | string | 否 | 导入时间结束，格式 yyyy-MM-dd |
| PageIndex | int | 否 | 页码，默认1 |
| PageSize | int | 否 | 每页数量，默认20，最大100 |
| IsByTime | bool | 否 | 是否按时间排序 |
| MaxId | long | 否 | 最大ID，用于增量查询 |

class Program
{

        var request = new VipSalePageRequest
        {
            ShopCode = "0112616",
            OldCode = "",
            VipCode = "",
            WxOpenID = "",
            WxUnionID = "",
            MobileNo = "18550206512",
            DataOrigin = 7,
            SaleDateStart = "2022-03-14",
            SaleDateEnd = "2022-04-15",
            ImportTimeStart = "2022-04-15",
            ImportTimeEnd = "2022-04-15",
            PageIndex = 1,
            PageSize = 100,
            IsByTime = true,
            MaxId = 1000
        };

        var result = VipSaleService.GetVipSalePage(request);

        if (result.Status && result.Result != null)
        {
            foreach (var sale in result.Result)
            {
                Console.WriteLine($"销售ID: {sale.SaleId}");
                Console.WriteLine($"订单编号: {sale.SaleNo}");
                Console.WriteLine($"门店: {sale.ShopName}");

                Console.WriteLine($"销售日期: {sale.SaleDate}");
                Console.WriteLine($"销售金额: {sale.SaleMoney}");
                Console.WriteLine($"订单状态: {sale.SaleType}");
                Console.WriteLine($"总数量: {sale.TotalCount}");
                
                if (sale.Dtls != null && sale.Dtls.Count > 0)
                {
                    Console.WriteLine("商品明细:");
                    foreach (var dtl in sale.Dtls)
                    {
                        Console.WriteLine($"  商品: {dtl.ProdCode}, 数量: {dtl.SaleQty}, 金额: {dtl.SaleMoney}");

                }
                Console.WriteLine("---");
            }
        }
        else
        {
            Console.WriteLine($"错误码: {result.StatusCode}, 错误信息: {result.Msg}");
        }
    }
}
