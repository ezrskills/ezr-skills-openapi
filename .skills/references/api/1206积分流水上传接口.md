### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1206 |
| 接口名称 | 积分流水上传 |
| 接口地址 | /api/cvip/VipBonusSet |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于上传会员积分流水记录，支持积分的增加或扣减操作，并可设置积分有效期。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 否* | 会员线下卡号 |
| Code | string | 否* | 会员电子卡号 |
| WxOpenID | string | 否* | 会员微信OpenID |
| TransBonus | int | 是 | 变动积分数量 |
| TradeNo | string | 是 | 交易流水号 |
| ChangeTime | string | 是 | 变动时间，格式：yyyy-MM-dd HH:mm:ss |
| EffectDate | int | 否 | 生效日期，0代表立即生效 |
| ValidityDate | int | 否 | 有效期截止日期，格式：yyyyMMdd |
| TransOrigin | int | 否 | 交易来源编码 |
| Remark | string | 否 | 备注说明 |
| RelationCode | string | 否 | 关联编码 |
| IgnoreMsg | int | 否 | 忽略消息标识 |
| DataOrigin | int | 否 | 数据来源编码 |
| ShopCode | string | 否 | 门店编码 |
| TradeShopCode | string | 否 | 交易门店编码 |

> *会员标识参数（OldCode、Code、WxOpenID）至少填写一个
