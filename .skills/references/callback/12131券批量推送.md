## 概述

本文档描述如何对接EZR开放平台的推送回调接口。推送回调与普通接口的主要区别在于：

- 推送没有现成的接口地址，需要自定义接口地址
- 推送是对接其他第三方的接口或者自定义业务处理

### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 12131 |
| 接口名称 | 券批量推送 |
| 接口地址 | /api/Coupon/CouponBatchSend |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

会员在EZR微信H5页面进行积分兑换或其它活动获得券后，EZR系统会根据该接口批量同步券数据给第三方系统，用于第三方系统线下核销券。与1213接口的区别在于本接口支持批量推送多张券信息。

## 注意事项

1. **批量处理**：Args参数解析后是**数组**，不是单个对象，需要使用 `List<T>` 接收
2. **Controller命名**：Controller名称应具有明确的业务含义
3. **Action命名**：Action名称应清晰表达业务用途
4. **参数解析**：使用 `FastJsonSerializer.FromJson<List<T>>` 解析Args参数
5. **异常处理**：统一使用 try-catch 捕获异常并返回错误信息
6. **券类型处理**：根据CoupType字段区分不同券类型（代金券、折扣券、促销券）进行业务处理
7. **有效期判断**：注意EndDate可能为"2099-12-31"表示永久有效
8. **性能考虑**：批量推送时注意处理性能，可考虑分批处理或异步处理
