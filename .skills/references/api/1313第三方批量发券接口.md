### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1313 |
| 接口名称 | 第三方批量发券 |
| 接口地址 | /api/cvip/coupbatchsend |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于批量向会员发放优惠券，支持通过券库ID或券编码发放，适用于营销活动、会员关怀等批量发券场景。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| CoupName | string | 是 | 券名称 |
| CoupGrpId | string | 是 | 券库ID |
| CoupType | int | 是 | 券类型 |
| PromotionCode | string | 否 | 活动编码 |
| CoupValue | decimal | 是 | 券面额 |
| BegDate | string | 是 | 有效期开始，格式 yyyy-MM-dd |
| EndDate | string | 是 | 有效期结束，格式 yyyy-MM-dd |
| ValidType | string | 是 | 有效期类型：TS=固定时间 |
| PromotionType | string | 否 | 促销类型 |
| CouponPriceLimit | decimal | 否 | 使用门槛金额 |
| Guide | string | 否 | 使用说明 |
| IsMore | bool | 否 | 是否允许多张 |
| CoupGrpCode | string | 否 | 券库编码 |
| IsCanGiveFriend | bool | 否 | 是否可转赠 |
| IsAllowBuyMore | bool | 否 | 是否允许多买 |
| AllowMaxBuyNum | int | 否 | 最大购买数量 |
| IsAllowPositive | bool | 否 | 是否允许正数 |
| SendVipList | array | 是 | 发券会员列表 |
| IsSingleCoupon | bool | 否 | 是否单券 |
| IsRemainValid | int | 否 | 是否保持有效 |
| NewAddCouponValidDays | string | 否 | 新增券有效天数 |

### 发券会员参数（SendVipList项）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 是 | 会员线下卡号 |
| WxOpenID | string | 否 | 微信OpenID |
| MobileNo | string | 否 | 手机号码 |
| CoupNo | string | 否 | 券编号 |
| Password | string | 否 | 券密码 |

            {

                StatusCode = 1001,
                Msg = "请求参数不能为空"

// 第三方批量发券请求参数（接口编号：1313）
public class CoupBatchSendRequest

    /// 活动编码

    /// 是否允许多张
    /// </summary>
    public bool IsMore { get; set; }

    /// <summary>
    /// 券库编码
