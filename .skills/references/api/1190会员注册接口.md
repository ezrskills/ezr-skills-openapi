所有接口的外层请求参数结构一致：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名，参见签名规则 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |

### 会员注册（1190）

#### 接口基本信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1190 |
| 接口名称 | 会员注册 |
| 接口地址 | `/api/cvip/regvip` |
| 请求方式 | POST |
| 功能描述 | 注册新会员，常提供给第三方线上官网等注册使用 |

#### 业务请求参数（Args）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| MobileNo | string | 是 | 手机号码 |
| PassWord | string | 否 | 用户密码（最多32位） |
| WxOpenId | string | 否 | 微信OpenId（最多32位） |
| WxUnionId | string | 否 | 微信UnionID（28位） |
| WxCode | string | 否 | 微信Code（最多20位） |
| NickName | string | 否 | 会员昵称（最多32位） |
| Name | string | 否 | 会员姓名 |
| Sex | string | 否 | 会员性别：0=未知，1=男，2=女 |
| Birthday | string | 否 | 会员生日（yyyy-MM-dd格式） |
| QqNo | string | 否 | QQ号码（最多20位） |
| RegShop | string | 否 | 开卡门店编码（最多16位） |
| RegUser | string | 否 | 开卡导购工号（最多32位） |
| RegTime | string | 否 | 注册时间 |
| ServShop | string | 否 | 服务门店编码 |
| ServUser | string | 否 | 服务导购工号 |
| Province | string | 否 | 省份 |
| City | string | 否 | 城市 |
| County | string | 否 | 区县 |
| InviteUser | string | 否 | 邀请导购工号 |
| RegSource | short | 否 | 入会渠道/来源 |
| GiveGift | bool | 否 | 注册送礼，默认false |
| UseDefaultShop | int | 否 | 是否使用默认门店作为开卡门店（1=使用默认门店，0=必须传RegShop） |
| Extends | array | 否 | 会员拓展字段列表 |

#### Extends 拓展字段结构

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| FieldName | string | 是 | 拓展字段名称 |
| Value | string | 是 | 拓展字段值 |

#### 业务响应参数（Result）

| 参数名 | 类型 | 说明 |

| OldCode | string | 会员线下卡号 |

| County | string | 区县 |

using System;
using System.Collections.Generic;
using EZP.Framework.Util.HttpClientFactory;

/// <summary>
/// 会员注册服务
/// </summary>
public static class VipRegService
{
    private static readonly IEZROpenApiClient _openApiClient = EZP.Framework.Util.HttpClientFactory.EzpFrameworkDI.GetRequiredService<IEZROpenApiClient>();

    /// <summary>
    /// [EZR-API:1190] 注册会员
    /// 注册会员
    /// </summary>
    /// <param name="request">请求参数</param>
    /// <returns></returns>
    public static BaseApiResInfo<VipRegResult> RegisterVip(VipRegRequest request)
    {
        if (string.IsNullOrWhiteSpace(request.MobileNo))
        {
            return new BaseApiResInfo<VipRegResult>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "手机号码不可为空"
            };
        }

        return _openApiClient.PostOpenApi<VipRegRequest, VipRegResult>("/api/cvip/regvip", request);
    }
}

        }
        else
        {

        }
    }
