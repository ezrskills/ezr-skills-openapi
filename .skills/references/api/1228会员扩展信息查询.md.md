### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1228 |
| 接口名称 | 会员扩展属性 |
| 接口地址 | /api/cvip/getextends |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于查询会员的扩展属性信息，支持获取会员完整档案信息，包含基础信息和品牌自定义扩展字段，适用于会员详情查询、会员信息同步场景。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 否* | 会员线下卡号 |
| Code | string | 否* | 会员线上卡号 |
| MobileNo | string | 否* | 手机号 |
| WxOpenID | string | 否* | 微信OpenID |
| WxUnionID | string | 否* | 微信UnionID |

> *以上参数至少填一个

### 请求示例

```json
{
    "AppId": "EZP-ZhuTest02",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260324143052",
    "AppSystem": "CRM",
    "Args": "{\"OldCode\":\"EZ00000277735638\",\"Code\":\"\",\"MobileNo\":\"\",\"WxOpenID\":\"\",\"WxUnionID\":\"\"}"
}
```
