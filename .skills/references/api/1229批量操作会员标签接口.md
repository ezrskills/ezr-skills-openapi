## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON数组字符串，数组中每个元素包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 否* | 会员线下卡号 |
| Code | string | 否* | 会员电子卡号 |
| WxOpenID | string | 否* | 微信OpenID |
| WxUnionID | string | 否* | 微信UnionID |
| Tags | string | 是 | 标签名称，多个用逗号分隔，如："白金卡,大款,高帅富" |
| TagIds | string | 否 | 标签ID，多个用逗号分隔 |
| AddType | int | 是 | 操作类型：1=添加标签；2=删除标签 |

> *会员标识参数（OldCode、Code、WxOpenID、WxUnionID）至少填写一个

}
