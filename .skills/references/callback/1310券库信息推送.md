## 概述

本文档描述如何对接EZR开放平台的推送回调接口。推送回调与普通接口的主要区别在于：

- 推送没有现成的接口地址，需要自定义接口地址
- 推送是对接其他第三方的接口或者自定义业务处理

### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1310 |
| 接口名称 | 券库信息推送 |
| 接口地址 | /api/Coupon/CoupGrpChange |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

当券库信息发生变更后（新增或编辑），EZR系统会通过该接口实时推送券库信息给第三方系统，用于第三方系统同步券库配置。

## 注意事项

1. **Controller命名**：Controller名称应具有明确的业务含义
2. **Action命名**：Action名称应清晰表达业务用途
3. **参数解析**：使用 `FastJsonSerializer.FromJson` 解析Args参数
4. **异常处理**：统一使用 try-catch 捕获异常并返回错误信息
5. **ChangeType判断**：C表示新增券库，U表示编辑券库
6. **券类型说明**：DJ=代金券，ZK=折扣券，CX=促销券
