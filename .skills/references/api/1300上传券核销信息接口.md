### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1300 |
| 接口名称 | 上传券核销信息 |
| 接口地址 | /api/cvip/CoupStatusSync |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于同步券核销状态信息到EZR平台，适用于第三方系统核销券后同步状态到EZR。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| CoupNos | array | 是 | 券编号列表 |
| ShopCode | string | 是 | 门店编码 |
| SalesNo | string | 否 | 销售单号 |
| ConsumeTime | string | 是 | 核销时间，格式 yyyy-MM-dd HH:mm:ss |
| ConsumeUser | string | 否 | 核销人 |
| SalesMoney | decimal | 否 | 销售金额 |

### 请求示例

```json
{
    "AppId": "1001",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260323143052",
    "AppSystem": "POS",
    "Args": "{\"CoupNos\":[\"00000000000487567346\",\"00000000000487567347\"],\"ShopCode\":\"HMGSTC\",\"SalesNo\":\"0000123002\",\"ConsumeTime\":\"2026-04-16 12:30:10\",\"ConsumeUser\":\"0010\",\"SalesMoney\":990}"
}
```

## 响应结构

### 标准响应格式

```json
{
    "Sign": "8FE4BCFACBEE21FD9BF4B29D199493CA8B9BC633",
    "Result": 2,
    "Status": true,
    "StatusCode": 200,
    "Msg": "成功",
    "Timestamp": "20260416143849"
}
```

### 响应参数说明

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Status | bool | 请求是否成功 |
| StatusCode | int | 状态码，200表示成功 |
| Msg | string | 响应消息 |
| Sign | string | 响应签名 |
| Timestamp | string | 响应时间戳 |
| Result | int | 核销成功数量 |

## 完整示例代码

### 业务服务示例

```csharp
using System;
using System.Collections.Generic;
using EZP.Framework.Util.HttpClientFactory;
using EZR.OP.ThirdPartyProxy.Bussiness.OpenApi.Client;

/// <summary>
/// 券核销服务
/// </summary>
public static class CouponStatusService
{
    private static readonly IEZROpenApiClient _openApiClient = EZP.Framework.Util.HttpClientFactory.EzpFrameworkDI.GetRequiredService<IEZROpenApiClient>();

    /// <summary>
    /// [EZR-API:1300] 上传券核销信息
    /// 上传券核销信息（接口编号：1300）
    /// </summary>
    /// <param name="request">请求参数</param>
    /// <returns></returns>
    public static BaseApiResInfo<int> SyncCoupStatus(CoupStatusSyncRequest request)
    {
        if (request == null)
        {
            return new BaseApiResInfo<int>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "请求参数不能为空"
            };
        }

        if (request.CoupNos == null || request.CoupNos.Count == 0)
        {
            return new BaseApiResInfo<int>
            {
                Status = false,
                StatusCode = 1002,
                Msg = "券编号列表不能为空"
            };
        }

        if (string.IsNullOrWhiteSpace(request.ShopCode))
        {
            return new BaseApiResInfo<int>
            {
                Status = false,
                StatusCode = 1003,
                Msg = "门店编码不能为空"
            };
        }

        if (string.IsNullOrWhiteSpace(request.ConsumeTime))
        {
            return new BaseApiResInfo<int>
            {
                Status = false,
                StatusCode = 1004,
                Msg = "核销时间不能为空"
            };
        }

        return _openApiClient.PostOpenApi<CoupStatusSyncRequest, int>("/api/cvip/CoupStatusSync", request);
    }
}

// 券核销状态同步请求参数（接口编号：1300）
public class CoupStatusSyncRequest
{
    /// <summary>
    /// 券编号列表
    /// </summary>
    public List<string> CoupNos { get; set; }

    /// <summary>
    /// 门店编码
    /// </summary>
    public string ShopCode { get; set; }

    /// <summary>
    /// 销售单号
    /// </summary>
    public string SalesNo { get; set; }

    /// <summary>
    /// 核销时间，格式 yyyy-MM-dd HH:mm:ss
    /// </summary>
    public string ConsumeTime { get; set; }

    /// <summary>
    /// 核销人
    /// </summary>
    public string ConsumeUser { get; set; }

    /// <summary>
    /// 销售金额
    /// </summary>
    public decimal? SalesMoney { get; set; }
}

// 使用示例
class Program
{
    static void Main()
    {
        var request = new CoupStatusSyncRequest
        {
            CoupNos = new List<string> { "00000000000487567346", "00000000000487567347" },
            ShopCode = "HMGSTC",
            SalesNo = "0000123002",
            ConsumeTime = "2026-04-16 12:30:10",
            ConsumeUser = "0010",
            SalesMoney = 990
        };

        var result = CouponStatusService.SyncCoupStatus(request);

        if (result.Status)
        {
            Console.WriteLine($"券核销信息上传成功，核销成功数量: {result.Result}");
        }
        else
        {
            Console.WriteLine($"错误码: {result.StatusCode}, 错误信息: {result.Msg}");
        }
    }
}
```
