## 查询接口文档

根据接口编号查询对应文档：

1. **API接口**：读取 `references/api/{编号}*.md`
2. **回调接口**：读取 `references/callback/{编号}*.md`

使用 Glob 工具搜索：
```
references/api/1190*.md
references/callback/1210*.md
```
