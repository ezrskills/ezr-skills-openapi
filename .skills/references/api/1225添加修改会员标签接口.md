## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 否* | 会员线下卡号 |
| Code | string | 否* | 会员电子卡号 |
| MobileNo | string | 否* | 手机号码 |
| WxOpenID | string | 否* | 微信OpenID |
| WxUnionID | string | 否* | 微信UnionID |
| Tags | string | 是 | 标签名称，多个用逗号分隔，如："白金卡,大款,高帅富" |
| TagIds | string | 否 | 标签ID，多个用逗号分隔 |
| AddType | int | 是 | 操作类型：1=添加标签；2=删除标签 |

> *以上会员标识参数至少填写一个

### 请求示例

```json
{
    "AppId": "EZP-ZhuTest02",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260324143052",
    "AppSystem": "CRM",
    "Args": "{\"OldCode\":\"000008\",\"Code\":\"000008\",\"MobileNo\":\"000008\",\"WxOpenID\":\"xxxxxxxxx\",\"WxUnionID\":\"xxxxxxxxxxxxxx\",\"Tags\":\"白金卡,大款,高帅富\",\"TagIds\":\"\",\"AddType\":1}"
}
```
