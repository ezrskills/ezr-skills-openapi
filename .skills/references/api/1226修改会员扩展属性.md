## 请求结构

### 外层请求参数

所有接口的外层请求参数结构一致：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名，参见签名规则 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串，结构因接口而异 |

### 请求示例

```json
{
    "AppId": "1001",

    "Timestamp": "20260316143052",
    "AppSystem": "ERP",
    "Args": "{\"OldCode\":\"EZ00000277735638\",\"Code\":\"000008\",\"MobileNo\":\"000008\",\"WxOpenID\":\"xxxxxxxxx\",\"Extends\":[{\"FieldName\":\"爱好\",\"Value\":\"唱歌\"}]}"
```

## 响应结构

### 标准响应格式

```json
{
    "Status": true,
    "StatusCode": 200,
    "Msg": "成功",
    "Sign": "响应签名",
    "Timestamp": "20260316143052",
    "Result": {
        // 业务返回数据，根据具体接口而定
    }
}
```

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Status | bool | 请求是否成功 |
| StatusCode | int | 状态码，200表示成功 |
| Msg | string | 响应消息 |
| Sign | string | 响应签名，可用于验证响应真实性 |
| Timestamp | string | 响应时间戳 |
| Result | object | 业务返回数据，结构因接口而异 |

### 响应签名验证

响应签名生成规则与请求签名相同：
```
Sign = SHA1("AppId={AppId}&Timestamp={Timestamp}&Token={Token}")
```

## 接口详情

### 修改会员扩展属性（1226）

#### 接口基本信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1226 |
| 接口名称 | 修改会员扩展属性 |
| 接口地址 | `/api/cvip/UpdateExtends` |
| 请求方式 | POST |
| 功能描述 | 修改会员的自定义扩展字段值 |

#### 业务请求参数（Args）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 否* | 会员线下卡号（最多80位） |
| Code | string | 否* | 会员线上卡号（最多20位） |
| MobileNo | string | 否* | 手机号码 |
| WxOpenID | string | 否* | 微信OpenID |
| Extends | array | 是 | 拓展字段列表 |

> *OldCode、Code、MobileNo、WxOpenID 至少填写一个

#### Extends 拓展字段结构

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| FieldName | string | 是 | 拓展字段名称（需与品牌配置的拓展字段名称一致） |
| Value | string | 是 | 拓展字段值 |

#### 业务响应参数（Result）

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Result | int | 修改成功的记录数 |

#### 请求示例

```json
{
    "AppId": "1001",
    "Sign": "A1B2C3D4E5F6G7H8I9J0",
    "Timestamp": "20260316143052",
    "AppSystem": "ERP",
    "Args": "{\"OldCode\":\"EZ00000277735638\",\"Code\":\"000008\",\"MobileNo\":\"000008\",\"WxOpenID\":\"xxxxxxxxx\",\"Extends\":[{\"FieldName\":\"爱好\",\"Value\":\"唱歌\"}]}"
}
```

#### 响应示例

**成功响应**
```json
{
    "Status": true,
    "StatusCode": 200,
    "Msg": "成功",
    "Sign": "RESPONSE_SIGN_VALUE",
    "Timestamp": "20260316143052",
    "Result": 1
}
```

```csharp
using System;
using System.Collections.Generic;
using EZP.Framework.Util.HttpClientFactory;
using EZR.OP.ThirdPartyProxy.Bussiness.OpenApi.Client;

/// <summary>
/// 会员扩展属性服务
/// </summary>
public static class VipExtendsService
{
    private static readonly IEZROpenApiClient _openApiClient = EZP.Framework.Util.HttpClientFactory.EzpFrameworkDI.GetRequiredService<IEZROpenApiClient>();

    /// <summary>
    /// [EZR-API:1226] 修改会员扩展属性
    /// 修改会员扩展属性
    /// </summary>
    /// <param name="request">请求参数</param>
    /// <returns></returns>
    public static BaseApiResInfo<int> UpdateExtends(VipExtendsUpdateRequest request)
    {
        if (string.IsNullOrWhiteSpace(request.OldCode) &&
            string.IsNullOrWhiteSpace(request.Code) &&
            string.IsNullOrWhiteSpace(request.MobileNo) &&
            string.IsNullOrWhiteSpace(request.WxOpenID))
        {
            return new BaseApiResInfo<int>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "会员线下卡号/线上卡号/手机号/微信OpenID至少有一个不能为空"
            };
        }

        if (request.Extends == null || request.Extends.Count == 0)
        {
            return new BaseApiResInfo<int>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "拓展字段不能为空"
            };
        }

        return _openApiClient.PostOpenApi<VipExtendsUpdateRequest, int>("/api/cvip/UpdateExtends", request);
    }
}

// 修改会员扩展属性请求参数（接口编号：1226）
public class VipExtendsUpdateRequest
{

    /// 拓展字段列表

}

// 拓展字段
```
