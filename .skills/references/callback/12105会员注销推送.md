## 概述

本文档描述如何对接EZR开放平台的推送回调接口。推送回调与普通接口的主要区别在于：

- 推送没有现成的接口地址，需要自定义接口地址
- 推送是对接其他第三方的接口或者自定义业务处理

### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 12105 |
| 接口名称 | 会员注销推送 |
| 接口地址 | /api/CVip/VipCancel |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

当会员进行注销操作时，EZR系统会通过该接口实时推送会员注销信息给第三方系统，用于第三方系统同步处理会员注销相关的业务逻辑。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后为会员注销信息对象，包含以下字段：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| OldCode | string | 会员线下卡号 |

### 请求示例

```json
{
    "AppId": "1001",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260323143052",
    "AppSystem": "CRM",
    "Args": "{\"OldCode\":\"VIP001\"}"
}
```

## 注意事项

1. **Controller命名**：Controller名称应具有明确的业务含义
2. **Action命名**：Action名称应清晰表达业务用途
3. **参数解析**：使用 `FastJsonSerializer.FromJson` 解析Args参数
4. **异常处理**：统一使用 try-catch 捕获异常并返回错误信息
5. **会员识别**：通过OldCode（线下卡号）识别被注销的会员
6. **数据处理**：会员注销后，需妥善处理会员关联的业务数据
