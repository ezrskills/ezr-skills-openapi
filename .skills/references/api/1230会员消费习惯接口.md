### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1230 |
| 接口名称 | 会员消费习惯 |
| 接口地址 | /api/cvip/getbehavior |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于查询会员消费习惯信息，包含消费偏好、购买周期、客单价等统计数据，适用于会员画像分析、精准营销等场景。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| MobileNo | string | 是 | 会员手机号 |

### 请求示例

```json
{
```

```csharp
using EZR.OP.ThirdPartyProxy.Bussiness.OpenApi.Client;

/// <summary>
/// 会员消费习惯查询服务
/// </summary>
public static class VipBehaviorService
{
    private static readonly IEZROpenApiClient _openApiClient = EZP.Framework.Util.HttpClientFactory.EzpFrameworkDI.GetRequiredService<IEZROpenApiClient>();

    /// <summary>
    /// [EZR-API:1230] 会员消费习惯查询
    /// 根据手机号查询会员消费习惯（接口编号：1230）
    /// </summary>
    /// <param name="mobileNo">会员手机号</param>
    /// <returns>消费习惯信息</returns>
    public static BaseApiResInfo<VipBehaviorResult> GetVipBehavior(string mobileNo)
    {
        if (string.IsNullOrWhiteSpace(mobileNo))
        {
            return new BaseApiResInfo<VipBehaviorResult>
            {
                Status = false,
                StatusCode = 1001,
                Msg = "手机号不能为空"
            };
        }

        var request = new VipBehaviorRequest
        {
            MobileNo = mobileNo
        };

        return _openApiClient.PostOpenApi<VipBehaviorRequest, VipBehaviorResult>("/api/cvip/getbehavior", request);
    }
}
```
