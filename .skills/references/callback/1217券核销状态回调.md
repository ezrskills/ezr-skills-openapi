## 概述

本文档描述如何对接EZR开放平台的推送回调接口。推送回调与普通接口的主要区别在于：

- 推送没有现成的接口地址，需要自定义接口地址
- 推送是对接其他第三方的接口或者自定义业务处理

### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1217 |
| 接口名称 | 券核销状态回调 |
| 接口地址 | /api/Coupon/CouponConsume |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

EZR系统可以通过该接口，将券核销的状态推送给第三方系统。只处理EZR接口核销券或EZR内部核销券的情况。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后为券核销状态信息对象，包含以下字段：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| CoupId | long | 券ID |
| Brand | string | 所属品牌编码 |
| Code | string | 券号码 |
| OrderCode | string | 订单号码 |
| ConsumeTime | string | 核销时间（yyyy-MM-dd HH:mm:ss格式） |
| OrigSystem | string | 发放来源系统 |
| ConsumeShop | string | 核销门店编码 |
| OutSysId | int | 发放来源系统ID（-2=Mall券，-1=通用券） |
| OldCode | string | 会员线下卡号 |
| MobileNo | string | 手机号码 |
| CoupGrpCode | string | 券外部编码 |
| CouponUseAmount | decimal | 抵扣金额，每单只有一个抵扣金额 |
| CoupType | int | 券类型：1=品牌代金券；2=品牌折扣券；3=品牌促销券 |
| UseSystem | string | 使用系统 |
| SalesMoney | string | 券核销金额/订单金额 |
| CouponUseVal | string | 订单使用价值 |
| ConsumeOutSysId | int | 核销来源系统ID |

## 注意事项

1. **Controller命名**：Controller名称应具有明确的业务含义
2. **Action命名**：Action名称应清晰表达业务用途
3. **参数解析**：使用 `FastJsonSerializer.FromJson` 解析Args参数
4. **异常处理**：统一使用 try-catch 捕获异常并返回错误信息
5. **业务处理**：接收到推送后，需要更新本地券的核销状态
6. **OutSysId判断**：-2表示Mall券，-1表示通用券
