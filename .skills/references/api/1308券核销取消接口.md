### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1308 |
| 接口名称 | 券核销取消 |
| 接口地址 | /api/ccoup/coupcanceluse |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于取消已核销的优惠券，将券状态恢复为未使用状态，适用于核销撤销、交易取消等场景。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| CouponNo | string | 是 | 券编号 |
| Remark | string | 否 | 取消原因/备注 |
| CancelUser | string | 否 | 取消人 |
| ReturnOrderNo | string | 否 | 退货单号 |
| IsOnline | bool | 否 | 是否在线取消 |

### 请求示例

```json
{
    "AppId": "EZP-ZhuTest02",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260324143052",
    "AppSystem": "POS",
    "Args": "{\"CouponNo\":\"00000000000487567348\",\"Remark\":\"取消核销\",\"CancelUser\":\"\",\"ReturnOrderNo\":\"\",\"IsOnline\":false}"
}
```

## 响应结构

### 标准响应格式

```json
{
    "Sign": "A55696120AA7A2EA245E511290CD58DCA0AF1566",
    "Result": 1,
    "Status": true,
    "StatusCode": 200,
    "Msg": "成功",
    "Timestamp": "20260416144330"
}
```

### 响应参数说明

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Status | bool | 请求是否成功 |
| StatusCode | int | 状态码，200表示成功 |
| Msg | string | 响应消息 |
| Sign | string | 响应签名 |
| Timestamp | string | 响应时间戳 |
| Result | int | 成功取消的券数量 |
