### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1309 |
| 接口名称 | 新增券库 |
| 接口地址 | /api/ccoup/coupgrpadd |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于在EZR平台新增优惠券库配置，支持设置券库名称、面额、使用门槛、有效期等参数，适用于第三方系统同步券库配置场景。
