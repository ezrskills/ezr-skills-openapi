### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1307 |
| 接口名称 | 会员券获取 |
| 接口地址 | /api/ccoup/coupget |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于查询会员持有的优惠券信息，支持按券状态、券类型等条件筛选，返回券详细信息。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 否 | 会员线下卡号 |
| ShopCode | string | 否 | 门店编码 |
| Code | string | 否 | 会员编码 |
| MobileNo | string | 否 | 手机号码 |
| WxOpenID | string | 否 | 微信OpenID |
| JDPin | string | 否 | 京东Pin |
| CouponType | string | 否 | 券类型 |
| ShowAll | int | 否 | 是否显示全部：0=否；1=是 |
| UseSystem | string | 否 | 使用系统 |
| UseSystems | array | 否 | 使用系统列表 |

            }
        }

        {
            Console.WriteLine($"错误码: {result.StatusCode}, 错误信息: {result.Msg}");
