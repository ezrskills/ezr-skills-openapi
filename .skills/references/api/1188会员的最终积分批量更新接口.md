### 接口说明

#### 接口基础信息

| 项目 | 说明 |
|------|------|
| 接口编号 | 1188 |
| 接口名称 | 会员最终积分批量更新 |
| 接口地址 | /api/cvip/vipbonusfinalbatchset |
| 协议 | HTTPS |
| 请求方式 | POST |
| 数据格式 | application/x-www-form-urlencoded |
| 字符编码 | UTF-8 |

#### 功能描述

用于批量设置会员的最终积分值，直接修改会员积分余额，适用于积分初始化、积分调整、积分同步等批量操作场景。

## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| VipList | List&lt;VipBonusInfo&gt; | 是 | 会员积分列表 |

### 会员积分信息（VipBonusInfo）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| OldCode | string | 是 | 会员线下卡号 |
| Bonus | int | 是 | 积分余额（最终积分） |
| BonusTotal | int | 否 | 累计积分 |
| Reason | string | 否 | 变更原因 |
| OperateUser | string | 否 | 操作人 |

### 请求示例

```json
{
    "AppId": "EZP-ZhuTest02",
    "Sign": "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6Q7R8S9T0",
    "Timestamp": "20260324143052",
    "AppSystem": "ERP",
    "Args": "[{\"OldCode\":\"EZ00001230\",\"Bonus\":100},{\"OldCode\":\"EZ00001231\",\"Bonus\":100}]"
}
```
