## 请求结构

### 外层请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| AppId | string | 是 | 品牌编码，由 EZR 分配 |
| Sign | string | 是 | 请求签名 |
| Timestamp | string | 是 | 请求时间戳，格式 `yyyyMMddHHmmss` |
| AppSystem | string | 是 | 系统来源标识 |
| Args | string | 是 | 业务请求参数JSON字符串 |

### 业务请求参数（Args）

Args为JSON字符串，解析后包含以下字段：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| TransBonus | string | 是 | 扣减积分数量（负数，如"-100"） |
| OldCode | string | 否* | 会员线下卡号 |
| Code | string | 否* | 会员电子卡号 |
| WxOpenID | string | 否* | 微信OpenID |
| TradeNo | string | 是 | 交易流水号 |
| ShopCode | string | 否 | 门店编码 |
| TransOrigin | int | 否 | 交易来源编码 |
| ValidityDate | int | 否 | 有效期类型 |
| Remark | string | 否 | 备注说明 |
| CallBackUrl | string | 否 | 回调接口地址 |
| DataOrigin | string | 否 | 数据来源 |
| RelationCode | string | 否 | 关联编码 |

> *会员标识参数（OldCode、Code、WxOpenID）至少填写一个
